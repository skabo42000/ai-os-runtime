# Repository rules

Read README.md, config/policy.md and procedures/worker-rules.md before changes.
Keep the fictional offline demo independent of credentials, network and provider executables.
Preserve source containment, held-project gates, evidence validation and conservative recovery.
One writer per project. Do not commit operational state or private input.
Run focused checks while fixing defects, then the full offline suite once at the end.
Do not commit, push, deploy, send, spend or invoke live providers without explicit authorization.
